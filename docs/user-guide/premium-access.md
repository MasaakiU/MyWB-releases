# Premium Access

[← How to use MyWB](../user-guide.md)

Premium Access enables Quantification and band detection, lets you restore editable MyWB figures from PowerPoint, and lets an AI assistant work in the document you have open.

## Before you start

Connect to the internet before using a Premium feature for the first time.

## Features that use Premium Access

- [Quantification](quantify-bands.md) <img src="../assets/premium-badge.svg" alt="Premium" height="18" align="absmiddle">
- [Paste MyWB from PowerPoint](powerpoint-workflow.md#powerpoint-workflow) <img src="../assets/premium-badge.svg" alt="Premium" height="18" align="absmiddle">
- [Open the MyWB figures in a PowerPoint file](powerpoint-workflow.md#powerpoint-workflow) <img src="../assets/premium-badge.svg" alt="Premium" height="18" align="absmiddle">
- Band detection (**Auto Detect**, also **Marker/Blot > Auto Detect...**) <img src="../assets/premium-badge.svg" alt="Premium" height="18" align="absmiddle">
- [AI assistant access](ai-assistant.md) <img src="../assets/premium-badge.svg" alt="Premium" height="18" align="absmiddle">

Basic features include Marker/blot view, SVG Preview, copying a figure to PowerPoint, and opening or saving MyWB files.

## Verification

Premium Access is provided for personal, academic, and internal research uses permitted by the [MyWB License](../../LICENSE). MyWB must verify access online before the first use and at least once every 30 days. After a successful check, Premium features work offline for up to 30 days. When a check is due, MyWB checks online as you open a Premium feature, and a notice at the top of the window tells you when Premium Access needs your attention, for example when the next check is due.

## If Premium features are unavailable

1. Connect the computer to the internet.
2. Select **Help > License Status**.
3. Click **Check Now**, or retry the Premium operation.
4. If MyWB requires an update, [install the current release](../installation.md) and try again.

If the cached authorization expires before verification succeeds, Premium features are temporarily unavailable. Basic features and local files remain available.
