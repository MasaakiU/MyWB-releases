# Window overview

[← How to use MyWB](../user-guide.md)

Use this map to find the parts of the window named in this guide. The screenshot shows **Marker/blot view**.

<p align="center"><img src="../assets/screen_shots/window-overview.svg" alt="MyWB window with the left sidebar, marker and blot image panes, editing panels, Files panel, and Image Adjustments numbered 1 to 6" width="917"></p>

| Part | What it does |
| --- | --- |
| ① **Left sidebar** | Switch between **Marker/blot view**, **SVG Preview**, **Quantification**, and **Assembly View**. **AI assistant access** and **Copy SVG for PowerPoint** are at the bottom. |
| ② **Marker image pane** | Show the optional molecular-weight marker image and its marker positions. [Open an image](open-images.md#open-a-marker-or-blot-image). |
| ③ **Blot image pane** | Show the blot image, ROI, bands, and sample positions. [Select an ROI](edit-roi-and-labels.md#roi-management). |
| ④ **Markers**, **Bands**, and **Sample Lane Details** | Edit [marker and sample labels](edit-roi-and-labels.md#add-marker-and-sample-positions) and the [band table](detect-bands.md#use-the-band-table). |
| ⑤ **Files** | Browse the current folder, switch documents, and select panels in an assembly. [Use the Files panel](manage-mywb-files.md#use-the-files-panel). |
| ⑥ **Image Adjustments** | Adjust contrast, inversion, orientation, and other image controls. [Adjust images](adjust-images.md). |

The left sidebar stays in place when you switch views. **SVG Preview**, **Quantification**, and **Assembly View** replace the central image panes with a preview, measurements, or an assembly, along with their own settings on the left. See [Preview and design the figure](design-and-preview-figure.md), [Quantify bands](quantify-bands.md), or [Put panels together as an assembly](assemblies.md).
